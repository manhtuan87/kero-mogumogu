# ケロちゃん もぐもぐ

ロープを切って、カエルの「ケロちゃん」におやつを食べさせるゲームです（5〜6歳向け）。
ブラウザで動き、Android の Chrome から「アプリとしてインストール」できます（PWA）。

- 15ワールド × 12ステージ = 180ステージ（キャンディ／いちご／ドーナツ／クッキー／ごちゃまぜ）
  - ワールド1〜5：はじめて向け
  - ワールド6〜15：少し難しめ（操作が2〜4回、タイミングの余裕はワールド1〜5の約半分）
- しかけ：ロープ、しゃぼんだま、ふーふーくも、ゼリー、フック（くるくるピン）、うごくピン、トゲトゲ、ワープぼうし、くるくるトゲ
- 画像・音のファイルは使わず、すべてプログラムで描画・合成しています

## 遊び方（PC で試す）

```
python -m http.server 8765 --directory .
```

ブラウザで http://localhost:8765 を開きます。

## Android にインストール

1. GitHub Pages などで公開した URL を Android の Chrome で開く
2. メニュー（︙）→「アプリをインストール」または「ホーム画面に追加」
3. 一度開けば、オフラインでも遊べます

## おみせ（キャラクター）

- ステージで集めた★で、おともだちを買えます：ミミちゃん（うさぎ）★10・ニャーちゃん（ねこ）★20・ワンちゃん（いぬ）★30
- 買ったキャラクターは「えらぶ」で切り替えられ、全ステージでそのキャラクターがおやつを食べます
- 買い物で減るのは「おさいふの★」だけで、各ステージの★の記録は減りません

## おうちの方へ

- ケロちゃん ランド（メニュー）で決めた なまえ（ニックネーム）が、タイトル画面の上に出ます

- タイトル画面左上の家のボタンで、ゲームのメニュー「ケロちゃん ランド」（https://manhtuan87.github.io/）に もどれます

- タイトル画面左下の ⚙ ボタン → 管理者パスワードで、管理者メニューが開きます
  - 全ステージ解放（すべてのワールド・ステージを選べるようにする）
  - 記録をリセット（★・買ったキャラクターも最初に戻ります）
- 💡ボタンで、次にさわる場所を手のマークで教えてくれます

## 開発メモ

- ステージは `js/levels.js`（ワールド1〜5）と `js/levels-more.js`（ワールド6〜15）。各ステージには検証済みの解（`sol`）が入っていて、ヒントもこれを使います
- ワールド6〜15は `tools/design/gen.js` で候補を自動生成し、`tools/design/select.js` で12個ずつ選んでいます（`tools/design/preview.html?file=out/w6.jsonl` で候補を一覧表示）
- `node tools/verify.js` … 全ステージを自動プレイして、星3つでクリアできるか・タイミングの余裕を確認
- `node tools/solve.js 2-5` … ステージの解き方を探す
- 更新を配信するときは `sw.js` の `VERSION` を上げてください（アプリを開いたとき・アプリに戻ったときに新しい版を探し、見つかったら サーバーから直接 取り直して、タイトル画面で自動的に読み込み直します）
