# ステージ設計ツール

新しいステージを作るときに使った補助スクリプトです（Node.js で実行）。
どれも「候補ファイル」（`module.exports = { 名前: ステージ定義, ... }` の JS）を引数に取ります。

| スクリプト | 役割 |
|---|---|
| `auto.js` | 解き方を総当たりで探し、いちばん余裕のある解を選び、その道すじに星を置いて1行のステージ定義を出力 |
| `frogfit.js` | 最後の操作のタイミングに余裕が出るカエルの位置を探す（`needEvent: 'hook'` などで「フックに捕まってから」を条件にできる） |
| `fit2d.js` | 途中の操作と最後の操作の両方に余裕が出るカエルの位置を探す |
| `pathfrog.js` | 1回の操作で決まるステージで、おやつの道すじ上にカエルを置ける場所を列挙 |

できたステージは `js/levels.js` に追加し、`node tools/verify.js` で全ステージが星3つでクリアできることを確認してください。
